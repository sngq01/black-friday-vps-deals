## 延迟数字怎么读，CN2 GIA 和 9929 差在哪

先给判读标准：香港机房 45 ms 以内算好，亚洲其他地区 80 ms 以内可以，亚洲以外 170 ms 以内属于正常水平。超过就说明线路绕了。

术语上分清楚这几组：CN2 GIA 是电信精品网 AS4809，去程回程都走 CN2；CN2 GT 只有出国段走 CN2，国内段还是 163；商家只写"CN2"没注明 GIA 还是 GT 时，按 GT 预期更稳妥。9929 是联通精品网 AS9929（CUII），4837 是联通普通骨干 AS4837。移动这边 CMIN2 是精品网 AS58807，CMI 是国际普通出口 AS58453。"三网优化"这个词，得商家写明电信、联通、移动回程都走优化线路才算数。

表格里那些毫秒数的测量方式是：中国大陆两家公共测速网络的探针，每天北京时间凌晨五点测一家商家，各家轮测，大约十天轮到一次，每家运营商最多取 12 个探针、每个 ping 4 次，某一网丢包超过 20% 会直接标出来。**它不测带宽，也不测晚高峰**，所以 40 ms 不代表晚上八点看视频不卡，只说明路由没绕远。想看晚高峰表现，只能自己 ping 测试 IP 或者买月付试。
